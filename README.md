An enterprise-grade PowerShell module engineered around Zero-Trust principles to broker Just-In-Time (JIT) privileged access via Microsoft Entra ID Privileged Identity Management (PIM). The broker enforces pre-flight host compliance validation, validates ITSM incident justification, manages time-bounded role elevation, and emits structured SIEM-ready audit records.
